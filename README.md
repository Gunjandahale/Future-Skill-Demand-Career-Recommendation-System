
# 🚀 Future Skill Demand & Career Recommendation System – 2030

A beginner-friendly Python project that analyzes a user's skills, compares them with different career requirements, and recommends suitable career paths based on skill compatibility and sample future-demand scores.

> ⚠️ Note: The future-demand values used in this project are sample project scores, not real 2030 employment forecasts.

---

## 📌 Project Overview

The **Future Skill Demand & Career Recommendation System – 2030** is a terminal-based career guidance application developed using Python.

The system allows users to:

- Create their career profile
- Enter skill ratings
- View their profile
- Calculate career compatibility
- Rank careers
- Get personalized career recommendations
- Analyze skill gaps
- View sample future-demand scores
- Get personalized learning recommendations
- Save user information
- Generate a career analysis report

The project is designed as a **Basic Python Project – Version 1.0**.

---

## 🎯 Objectives

The main objectives of this project are:

1. Analyze the user's current technical and soft skills.
2. Compare user skills with career requirements.
3. Calculate career compatibility scores.
4. Rank suitable career options.
5. Recommend a suitable career.
6. Identify missing or weak skills.
7. Provide learning recommendations.
8. Generate a career analysis report.
